# Storybook Product Snapshot

Storybook is a Nimi App for authoring and playing interactive narrative
projects. It separates creator work from player experience through Studio,
Play, and a shared app-owned Engine.

The root authority object is the `storybook-truth-package`. It owns scenario
frame, agent cast, Storybook Bible, branching topology, state/ending matrix,
chapters, assets, evidence bindings, derivations, accepted feedback, projection
inputs, and optional Realm structural imports.

Storybook is genre-neutral. It is not a galgame-only, anime-only, adult-only,
prompt-only, or one-shot visual-novel generator.
